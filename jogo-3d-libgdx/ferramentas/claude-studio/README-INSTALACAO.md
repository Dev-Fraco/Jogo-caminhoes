# Claude Code Game Studios (instalado como ferramenta)

Cópia do projeto `Donchitos/Claude-Code-Game-Studios` (MIT), sem o histórico do git.

Ela está **inativa** de propósito: para o Claude Code usá-la, o conteúdo de `.claude/` e o
`CLAUDE.md` precisam estar na raiz do repositório aberto, e isso mudaria o comportamento das
sessões do jogo libGDX. Para usar a ferramenta, abra o Claude Code numa cópia desta pasta
(ou copie `.claude/` e `CLAUDE.md` para outra pasta de trabalho).

O estúdio é voltado a jogos de navegador (Vite e TypeScript) e motores como Godot, Unity e
Unreal. Não cobre libGDX/Java, então não substitui o fluxo atual do projeto.
