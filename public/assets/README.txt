WALLPAPER DO MENU PRINCIPAL
---------------------------
Coloque aqui a imagem de fundo com o nome exato:  wallpaper-menu.jpg

Sugestão: cena noturna de estádio lotado, treinador na beira do campo passando instruções aos jogadores.
Tamanho recomendado: 1920x1080 (ou maior), JPG ~300-600 KB. O lado esquerdo será escurecido para o menu.
Enquanto o arquivo não existir, o menu usa um fundo desenhado só com CSS (estádio à noite).
Para usar outro nome/caminho, altere WALLPAPER_URL em src/ui/MainMenu.tsx.
